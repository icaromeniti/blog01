# Meniti Pesca Aventura

Blog pessoal sobre pesca, experiências e grandes pescarias. 🎣

## Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica, utilizando HTML e CSS.

O objetivo foi criar um blog de pesca com uma identidade visual própria, apresentando histórias de pescarias, fotos e informações sobre as experiências.
